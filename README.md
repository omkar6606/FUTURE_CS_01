# FUTURE_CS_01

## Vulnerability Assessment Report – OWASP Juice Shop

This repository contains the submission for Cyber Security Task 1 assigned by Future Interns.

The task involved conducting a passive vulnerability assessment on the OWASP Juice Shop application using ethical and read-only testing techniques.

---

# Objective

The objective of this assessment was to:

- Perform passive reconnaissance
- Identify exposed services and configurations
- Review HTTP security headers
- Analyze cookie security
- Document findings professionally
- Recommend remediation measures

---

# Target Application

OWASP Juice Shop  
https://demo.owasp-juice.shop/

---

# Tools Used

- Nmap
- Browser Developer Tools
- OWASP Methodology
- Canva / MS Word for report preparation

---

# Assessment Scope

The assessment was limited to:

- Publicly accessible pages
- Passive analysis only
- Header inspection
- Cookie inspection
- Port and service enumeration

No exploitation or destructive testing was performed.

---

# Repository Structure

/screenshots → Assessment screenshots  
/nmap → Nmap scan results  
/report → Final vulnerability assessment report  
/evidence → Supporting notes and findings  

---

# Key Findings

- Missing secure cookie attributes
- Information disclosure through headers
- Open exposed services
- Weak security header configuration

---

# Disclaimer

This assessment was conducted strictly for educational and internship purposes under an authorized and ethical scope.

No exploitation, brute force attacks, or service disruption activities were performed.
